# 🎃 Pumpkin Journey

**Pumpkin Journey** is an immersive educational 2D platformer game built using the **Unity Engine**. Set in a mysterious fantasy world, players must navigate through a series of puzzles and challenges to escape a haunted graveyard while gaining knowledge along the way.

## 🎮 Game Features

- **Educational Puzzles**: Engaging brain-teasers that integrate learning into gameplay.
- **Atmospheric World**: A beautifully crafted fantasy environment with unique visual effects.
- **Interactive Learning**: Players collect "Knowledge Points" to progress through levels.
- **Dynamic Gameplay**: Smooth platforming mechanics and challenging obstacles.

## 🛠️ Technical Details

- **Engine**: Unity 2022.3+
- **Language**: C#
- **Graphics**: Custom shaders (ShaderLab) and high-quality 2D sprites.
- **Platform**: Designed for PC/Desktop.

## 📂 Project Structure

- `/Assets`: Game scripts, sprites, animations, and audio.
- `/Packages`: Unity package dependencies.
- `/ProjectSettings`: Engine configuration files.

## 🚀 How to Play

1. Download the latest release from the [Releases](https://github.com/naylannajwa/pumpkin-journey/releases) page.
2. Run the executable file.
3. Explore, solve puzzles, and escape the graveyard!
